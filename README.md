# Описание

Простой финансовый трекер, отображающий расходы средств. Включает в  свой функционал возможности фильтрации расходов по категориям и временному периоду.

## Установка
Для запуска потребуется nodejs и docker-compose, а так же подключение к сети интернет (для скачивания пакетов)

Используйте npm для установки зависимостей:

```bash
npm i
```
Установите необходимые образы и запустите контейнеры:
```bash
docker compose up
```

## Использование

Создайте и заполните данными файл .env по шаблону example.env в корне проекта

Запустите nodejs приложение:
```bash
npm start
```
